# 호치민 탐방 가이드

Sixman이 직접 확인한 호치민 여행 정보를 보여주는 스마트폰용 웹앱입니다.
먼저 호치민 한 도시로 시작하고, 나중에 다른 도시로 넓혀 갈 계획이에요.
Sixman의 기본 정보에 더해, 누구나 로그인 없이 새 장소를 알려줄 수 있어요. 관리자(Sixman)는 로그인해서 잘못된 제보를 삭제할 수 있어요.

## 들어 있는 파일

| 파일 | 하는 일 |
| --- | --- |
| `index.html` | 앱 화면 전부 (이 파일 하나로 돌아가요) |
| `manifest.webmanifest` | "홈 화면에 추가"했을 때 앱 이름·색·아이콘 |
| `sw.js` | 인터넷이 약할 때 마지막으로 본 화면을 보여줌 |
| `icon.svg` | 앱 아이콘 |
| `api/karaoke.js` | 금영 노래방 번호를 받아오는 무료 중계 함수 (Vercel이 자동으로 실행) |
| `images/` | 장소 사진 폴더 (`sample-pho.svg`: 샘플 그림). ATM·입국 QR 안내 그림은 `index.html` 안에 들어 있어서 폴더가 없어도 보여요 |
| `supabase-setup.sql` | 여행자 제보용 데이터베이스를 만드는 설정 (한 번만 실행) |
| `sheet-templates/` | 구글 시트에 붙여 넣을 칸 이름과 샘플 (장소·교통·팁) |

## 1. 구글 시트 만들기

1. 구글 시트를 새로 만들고 아래쪽 탭을 3개 만들어요: `장소`, `교통`, `팁`
2. `sheet-templates` 폴더의 CSV 파일을 각각의 탭에 가져오기(파일 → 가져오기) 해요.
3. 공유 설정에서 **편집자는 나만** 남겨요.
4. 샘플 줄은 지우고, 직접 확인한 장소로 채워요.

### 칸 설명 (장소 탭)

| 칸 | 쓰는 법 |
| --- | --- |
| 지역 | 1군 중심가, 3군, 4군, 5군 쩌런, 7군 푸미흥, 고밥(공항 근처), 빈탄, 타오디엔, 근교 중 하나 (동네 목록은 `index.html`의 `AREAS`에서 바꿀 수 있어요) |
| 분류 | 볼거리, 먹을거리, 카페, 숙소, 쇼핑, 마사지, 이발소, KTV, 놀거리, 환전/유심, 병원/약국 중 하나 |
| 전화 / 잘로 / 카톡 / 예약링크 | 가게 전화번호, Zalo 번호, 카카오톡 ID(또는 오픈채팅 링크), 예약 페이지 주소. 하나라도 있으면 '📞 예약' 표시가 붙고 장소 안내에 예약·연락 버튼이 생겨요 |
| 구분 | 한국, 중국, 베트남 중 하나 (한/중/베라고 써도 돼요). 장소 탭에서 이 구분으로 걸러 볼 수 있어요 |
| 이름 / 베트남어이름 | 한국어 이름과 베트남어 이름 |
| 주소 | 그랩에 붙여 넣을 베트남어 주소. **넣기 전에 그랩 앱에서 한 번 시험해 보세요.** |
| 안내 | Sixman의 한두 줄 설명 |
| 가격 / 확인한날 | 예: 1인분 약 5만 동 / 2026-10 |
| 공개 | O면 보이고 X면 숨겨요 |
| 사진 | 사진 주소. 여러 장이면 `|`로 나눠요 (예: `images/pho1.jpg|images/pho2.jpg`). 비워도 돼요 |
| 추천 | O면 홈 화면 "Sixman 추천 장소"에 나와요 |
| 위키 | 위키백과 문서 제목 (예: `Chợ Bến Thành`). 사진 칸이 비어 있으면 이 문서의 사진을 자동으로 보여줘요 |

> 칸 이름(첫 줄)은 바꾸지 마세요. 앱이 이 이름으로 내용을 찾아요.

### 장소 사진 넣는 법
1. 직접 찍은 사진을 GitHub 저장소의 `images` 폴더에 올려요 (예: `images/pho-hoa.jpg`).
   휴대폰 사진은 용량이 크니 가로 1200px 정도로 줄여서 올리면 앱이 빨라요.
2. 시트의 `사진` 칸에 `images/pho-hoa.jpg`처럼 적어요.
3. 다른 사람이 찍은 사진이나 인터넷에서 찾은 사진은 저작권 때문에 쓰지 마세요.

### 사진이 없을 때
모든 장소에 이미지가 나오도록 아래 순서로 보여줘요.
1. `사진` 칸에 적은 Sixman의 사진
2. 없으면 `위키` 칸(비어 있으면 볼거리·쇼핑·놀거리는 베트남어 이름)으로 위키백과의 자유 이용 사진을 자동으로 가져와요. 사진 아래에 '사진: 위키백과' 출처가 표시돼요.
3. 그것도 없으면 분류 색과 아이콘, 장소 이름으로 만든 그림 카드가 나와요.

### 앱 안의 구글 지도
장소 안내 화면 아래쪽에 구글 지도가 바로 보여요. API 키나 돈이 들지 않는 구글 지도 '퍼가기' 방식이에요.
지도는 `베트남어이름 + 주소`로 위치를 찾으니, 지도에 엉뚱한 곳이 나오면 시트의 베트남어 이름이나 주소를 고쳐 주세요.

## 2. 시트를 앱에 연결하기

1. 구글 시트에서 **파일 → 공유 → 웹에 게시**
2. 탭을 `장소`로, 형식을 **쉼표로 구분된 값(.csv)** 으로 고르고 게시 → 나온 주소 복사
3. `교통`, `팁` 탭도 똑같이 해서 주소 3개를 받아요.
4. `index.html`을 열어 맨 아래쪽 `CONFIG` 부분에 붙여 넣어요.

```js
const CONFIG = {
  PLACES_CSV: "여기에 장소 탭 주소",
  ROUTES_CSV: "여기에 교통 탭 주소",
  TIPS_CSV:   "여기에 팁 탭 주소"
};
```

비워 두면 샘플 데이터가 보여요. 웹에 게시한 주소는 **읽기 전용**이라, 주소를 아는 사람도 내용을 바꿀 수 없어요.

## 2-1. 여행자 제보 켜기 (Supabase, 무료)

누구나 새 장소를 올리고, 관리자만 지울 수 있게 하는 설정이에요. 처음 한 번만 하면 돼요.

1. [supabase.com](https://supabase.com)에 가입하고 **New project**를 만들어요 (무료 플랜, 지역은 Singapore 추천).
2. 왼쪽 **SQL Editor** → `supabase-setup.sql` 내용을 붙여 넣기 → `admin@example.com`을 **모두** 내 이메일로 바꾸고 **Run**. (메모장의 '바꾸기'로 한 번에 바꾸면 편해요)
3. 왼쪽 **Authentication → Users → Add user**에서 관리자 계정(같은 이메일 + 비밀번호)을 만들어요. "Auto Confirm User"를 체크하세요.
4. **Authentication → Sign In / Providers**에서 **Allow new users to sign up을 꺼요.** (다른 사람이 계정을 못 만들게)
5. **Project Settings → API**에서 `Project URL`과 `anon public` 키를 복사해 `index.html`의 `CONFIG`에 넣어요.

```js
SUPABASE_URL: "https://내프로젝트.supabase.co",
SUPABASE_ANON_KEY: "eyJ..."   // anon public 키 (공개돼도 괜찮은 키)
```

> `service_role` 키는 절대 넣지 마세요. 그 키는 모든 권한이 있는 비밀 키예요.

### 쓰는 법
- **누구나:** 장소 탭의 **＋ 새 장소 알려주기** → 동네·분류·이름·설명을 적고 올리기. 로그인 필요 없어요. 바로 앱에 '여행자 제보' 표시와 함께 나와요.
- **관리자:** 홈 화면 맨 아래 **관리자 로그인** → 어떤 장소든 열면 **✏️ 사진·내용 고치기**가 나와요. 사진을 폰에서 바로 올리고, 대표 사진을 고르고, 설명·주소·가격을 고칠 수 있어요. 기본 장소는 '숨기기'와 '원래 내용으로 되돌리기'도 돼요.
- **관리자(제보 관리):** 홈 화면 맨 아래 **관리자 로그인** → 이메일·비밀번호. 로그인하면 제보마다 🗑️ 버튼이 생겨 삭제할 수 있고, 장소를 열면 ✏️ 고치기로 내용을 수정할 수 있어요. 관리자가 올린 장소는 'Sixman' 표시가 붙어요.
- 삭제 권한은 앱이 아니라 데이터베이스 규칙이 지켜요. 앱 코드를 고쳐도 관리자 계정 없이는 지울 수 없어요.

### 알아 둘 점
- 스팸 방지로 한 사람이 30초에 한 번만 올릴 수 있고, 글자 수 제한이 있어요. 그래도 장난 글이 올라올 수 있으니 가끔 확인해 주세요.
- 사진 올리기는 관리자만 할 수 있어요(부적절한 사진 위험). 일반 제보는 그림 카드나 위키백과 사진으로 보이고, 관리자가 나중에 사진을 넣을 수 있어요.
- 관리자가 앱에서 고친 기본 장소 내용은 Supabase의 `place_overrides`에 저장돼요. 구글 시트 내용보다 우선해서 보여요.
- Supabase 무료 플랜은 오래(약 1주일) 아무도 안 쓰면 잠시 멈출 수 있어요. 대시보드에서 다시 켜면 돼요.

## 3. GitHub에 올리고 Vercel로 열기

1. GitHub에서 새 저장소(예: `hcm-guide`)를 만들고 이 폴더의 파일을 모두 올려요.
2. Vercel에서 **Add New → Project → 그 저장소 Import → Deploy**
   (설정은 건드리지 않아도 돼요. 빌드 과정이 없는 일반 웹페이지예요.)
3. 생긴 주소(예: `hcm-guide.vercel.app`)를 스마트폰에서 열고 **홈 화면에 추가**하면 앱처럼 써요.

그다음부터는:
- **장소 정보 바꾸기** → 구글 시트만 고치면 돼요. 몇 분 안에 앱에 반영돼요.
- **화면 모양 바꾸기** → GitHub의 `index.html`을 고치면 Vercel이 자동으로 다시 올려요.

## 들어 있는 기능

| 탭 | 기능 |
| --- | --- |
| 홈 | Sixman 추천 장소, 여행 준비 팁 |
| 장소 | 동네·분류·한중베별 장소, 예약·연락(전화·Zalo·카톡·예약 링크, 베트남어 예약 메시지 만들기), KTV 분류 화면의 '노래 찾기'(금영 KY 번호), 주소 복사(그랩용), 이름 복사, 안내 화면 안에 사진과 구글 지도 |
| 교통 | 한국 → 인천공항(공항철도·버스타고·코레일톡 바로가기), 호치민 교통(공항→시내, 지하철, 근교 투어) + 12Go·Vexere |
| 비행기 | 항공사 입력 → 터미널 안내, 출발 전 체크, 베트남 입국 QR 작성 방법(8단계 + 사진 안내), 인천공항 실시간 안내, 인천·부산 → 호치민 항공권 찾기 |
| 통역 | 상황별 베트남어 회화(기본·식당·쇼핑·그랩·숙소·마사지/이발소·긴급·숫자), 🔊 발음 듣기, 크게 보여주기, 금액 크게 보여주기, 구글 번역·파파고 바로가기 |
| 검색 | 장소·교통·팁·베트남어 표현을 묶어서 검색 |
| 환전 | 한화·달러·동 자동 계산, 네이버 환율 바로가기, 트래블카드 ATM 인출 방법(8단계 + 사진 안내), VPBank ATM 목록 |
| 찜한 곳 | 내 폰에만 저장되는 장소 목록 |
| 제보·관리자 | 누구나 새 장소 올리기(로그인 없음), 관리자 로그인 후 삭제 |

### 환전 계산기에 대해
- 앱이 열리면 무료 환율 서비스(open.er-api.com, 키 필요 없음)에서 하루 한 번 바뀌는 환율을 받아와요.
- 네이버에서 본 환율을 '지금 쓰는 환율' 칸에 넣으면 그 값이 우선이고, 내 폰에 기억돼요.
- 네이버 환율은 공개 API가 없어서 자동으로 가져올 수 없어요. 대신 네이버 환율 화면 바로가기 버튼을 넣었어요.

### VPBank ATM
- 샘플의 VPBank ATM은 동네 이름으로 지도를 검색하는 임시 항목이에요. Sixman이 실제로 가 본 ATM의 정확한 주소로 바꿔 주세요.

### 노래방 번호에 대해
- 무료 공개 노래방 검색 서비스(api.manana.kr)의 금영 자료를 씁니다. 공식 금영 서비스가 아니라서 최신곡이 늦게 들어오거나 서비스가 멈출 수 있어요.
- 번호를 못 불러오면 '네이버에서 금영 번호 찾기' 버튼이 나와요.
- `api/karaoke.js`는 Vercel에서만 돌아가요. GitHub Pages 등 다른 곳에 올리면 브라우저가 직접 가져오기를 시도해요.

### 인천공항 터미널 목록 고치기
`index.html`의 `TERMINALS` 부분에 항공사 이름을 추가·수정하세요. 지금 제1터미널: 베트남항공, 비엣젯항공, 썬 푸꾸옥 항공, 제주항공, 티웨이항공, 이스타항공.

## 다른 도시로 넓힐 때
1. `index.html`에서 `CITY`(도시 이름)와 `AREAS`(동네 목록), `FROM_AIRPORTS`·항공권 도착 공항(SGN)을 바꿔요.
2. 그 도시용 구글 시트를 새로 만들어 `CONFIG`에 연결해요.
3. 도시가 여러 개가 되면 맨 위에 도시 선택을 다시 넣으면 돼요.
